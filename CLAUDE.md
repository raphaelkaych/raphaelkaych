# Instruções para agentes

README do perfil de Raphael Kaych no GitHub. Só `README.md` aparece no perfil; `capa.svg` é a imagem do topo.

## Regras

- Todo link do README aponta para algo publicado: rotas do portfólio em `https://raphael-kaych.raphaelvindex.chatgpt.site/` ou arquivos de `raphaelkaych/farol-de-integracoes` e dos repositórios dos laboratórios. Confira que cada link responde antes de abrir o PR.
- O conteúdo acompanha o portfólio. Ao renomear um laboratório, uma rota ou um arquivo no farol, atualize este README no mesmo ciclo.
- `capa.svg` usa só gradientes internos e fontes do sistema, porque o GitHub exibe o SVG como imagem e não carrega recursos externos. Mantenha `<title>`, `<desc>` e o texto alternativo do README de acordo com o conteúdo da capa.
- Português do Brasil, frases curtas, sem métricas que o portfólio não comprove.
- Trabalhe em branch própria e abra PR para `main`.
